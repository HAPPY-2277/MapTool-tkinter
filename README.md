# Spatial Data Quality Check Tool (Tkinter Version)

A simple desktop application for spatial data quality inspection, built with Python and Tkinter.

## Features

- Load and display map images (JPG, PNG, BMP, TIF)
- Load and view text files (TXT, CSV)
- Click to mark error locations on images
- Record error type and description
- Save/Load error records (JSON format)
- Export error reports (TXT format)

## Requirements

- Python 3.9+
- Pillow (PIL)

## Installation

```bash
pip install Pillow
```

## Usage

```bash
python MapTool-tkinter.py
```
